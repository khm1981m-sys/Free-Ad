MEHRSAM GAMING ADS MAX 3D — PHP + MySQL

نیازمندی‌ها:
- PHP 8.1 یا جدیدتر با افزونه‌های PDO MySQL و mbstring
- MySQL یا MariaDB
- هاست دارای HTTPS

راه‌اندازی:
1) فایل‌های پوشه را روی هاست قرار دهید؛ index.html در ریشه سایت باشد و پوشه api کنار آن.
2) در کنترل‌پنل هاست یک پایگاه داده و کاربر MySQL بسازید.
3) فایل database.sql را در phpMyAdmin وارد کنید. اگر نام دیتابیس را تغییر داده‌اید، خط CREATE DATABASE/USE را مطابق نام واقعی تنظیم کنید.
4) api/config.example.php را به api/config.php کپی کنید و اطلاعات واقعی دیتابیس را وارد کنید. config.php را منتشر یا به کسی ارسال نکنید.
5) در api/bootstrap.php تنظیمات session و اتصال DB آماده‌اند. روی HTTPS مقدار cookie_secure را true نگه دارید.
6) برای ساخت ادمین، از SSH/ترمینال وارد پوشه پروژه شوید و اجرا کنید:
   php create_admin.php
   نام کاربری و رمز قوی حداقل ۱۴ نویسه وارد کنید.
7) بعد از ساخت ادمین، فایل create_admin.php را از هاست حذف کنید.
8) صفحه سایت را با آدرس HTTPS باز کنید. ثبت تبلیغ ابتدا pending است و ادمین می‌تواند تبلیغ‌ها را تأیید، رد یا حذف کند.

نکات امنیتی:
- این پروژه رمزها را با password_hash/password_verify ذخیره می‌کند و از prepared statements استفاده می‌کند.
- در محیط واقعی HTTPS اجباری کنید، بکاپ بگیرید و PHP/هاست را به‌روز نگه دارید.
- برای جلوگیری از سوءاستفاده، محدودیت تلاش ورود، ایمیل بازیابی، محدودیت نرخ درخواست و بررسی دستی تبلیغات را در صورت عمومی شدن سایت اضافه کنید.
- لینک تصویر از سایت بیرونی بارگذاری می‌شود؛ اگر امکانش را دارید در مرحله بعدی آپلود تصویر با اعتبارسنجی MIME/اندازه و ذخیره‌سازی امن اضافه کنید.
- رمز ادمین در HTML یا JavaScript قرار ندارد.
